# Improvement Changelog

The environment began as one fixed-time PromQL task. It ended with five Prometheus episodes running through the same Harbor workflow. This is the evidence-to-decision record in between.

| Iteration | Evidence | Decision |
|---|---|---|
| First task | The clean parent failed five fixed-time subquery cases; the merged change passed them ([build log](docs/BUILD_LOG.md)) | Keep the pre-change source, short instruction, and external reward pattern |
| Five-task scope | Prometheus offered networking, query, and storage changes under one Go build ([suite registry](task_support/prometheus/suite.toml)) | Add Unix sockets, histogram rates, start timestamps, and stale WAL expiry to the same episode shape |
| Source lineage | Every clean-parent archive verified, and every registered upstream patch stack applied in order ([evidence ledger](docs/TASK_SUITE_EVIDENCE.md#registered-lineage)) | Pin each task to its own parent, archive hash, and exact patch stack |
| Actor source | Early task trees still carried repository provenance ([build log](docs/BUILD_LOG.md#29-august-five-task-family)) | Strip `.git`, remotes, commit metadata, reference solutions, verifier source, and hidden tests from every actor archive |
| Instructions | Early drafts named files, commands, root causes, and routine maintainer obligations ([final instructions](task_support/prometheus/tasks)) | Reduce each prompt to the incident and the new outcome the agent must deliver |
| First full Luna cohort | Luna-max passed 8/10: UDS, subquery, start timestamp, and WAL passed twice; histogram failed twice ([run table](docs/TASK_SUITE_EVIDENCE.md#historical-stock-agent-calibration)) | Inspect the solutions against the upstream changes before changing the task contracts |
| UDS reference stack | The first merged change let sockets sharing one authority cross streams ([build log](docs/BUILD_LOG.md)) | Include its direct pooling repair in the reference stack |
| UDS result handling | One correct solution removed a missing target while the first check required `up=0` ([failed experiments](docs/TASK_SUITE_EVIDENCE.md#failed-experiments-kept-in-the-record)) | Accept either fail-closed representation while keeping the TCP fallback trap |
| Histogram reference stack | The first histogram change still panicked on a mixed float and histogram window ([build log](docs/BUILD_LOG.md)) | Include its direct panic repair |
| Start-timestamp scope | The change touched 34 upstream files across chunks, WAL/WBL, blocks, flags, and query iteration ([build log](docs/BUILD_LOG.md#29-august-five-task-family)) | Treat it as a long-horizon storage episode and exclude later repair PRs |
| Trusted harness | Candidate or reference-added tests could shape the result ([boundary audit](docs/VERIFIER_PROVENANCE_AUDIT.md)) | Remove candidate tests, restore clean-parent harness files, and add verifier-owned cases |
| Shared episode boundary | Five task-specific test scripts did not yet behave like one environment ([boundary audit](docs/VERIFIER_PROVENANCE_AUDIT.md)) | Freeze one source-archive shape and hand it to a separate verifier for every task |
| External observation | UDS and subquery still ran important checks inside candidate test processes ([boundary audit](docs/VERIFIER_PROVENANCE_AUDIT.md)) | Drive those tasks from external controllers; inspect WAL and start-timestamp artifacts outside the candidate process; retain one linked histogram breadth test as a stated limit |
| Candidate runtime | Candidate programs inherited more process authority than the checks required ([build log](docs/BUILD_LOG.md#30-august-trust-boundary-rewrite)) | Run them as UID 65532 with an empty environment, no capabilities, `no_new_privs`, and resource limits |
| Daytona runs | Remote execution exposed a loopback assumption, an out-of-memory build, and a controller declaration error ([failed experiments](docs/TASK_SUITE_EVIDENCE.md#failed-experiments-kept-in-the-record)) | Fix the runtime assumptions, serialize Go compilation, and rerun the affected tasks |
| Histogram preflight | A working solution was rejected because an incompatible first sample remained in the range ([failed experiments](docs/TASK_SUITE_EVIDENCE.md#failed-experiments-kept-in-the-record)) | Check bucket-family compatibility independently before evaluating the result |
| Subquery timeout | One stock-agent patch passed verification but reached the 1800-second actor limit ([failed experiments](docs/TASK_SUITE_EVIDENCE.md#failed-experiments-kept-in-the-record)) | Raise only that actor budget to 3600 seconds and repeat its cases |
| Histogram tolerance | Review found an undocumented `1e-12` relative comparator in the external controller ([build log](docs/BUILD_LOG.md#30-august-candidate-calibration)) | Document its floating-point purpose, check it against the mutants, and rerun the matrix |
| Subquery controls | One implementation could return the same fabricated answer for every query ([build log](docs/BUILD_LOG.md)) | Randomize metric identities and add independent raw and arithmetic queries with known results |
| Start-timestamp collection | Go builds could leave `go.work.sum` in the submitted tree ([failed experiments](docs/TASK_SUITE_EVIDENCE.md#failed-experiments-kept-in-the-record)) | Remove the build byproduct before collection and repeat the cases |
| Start-timestamp experiment | Two Luna solutions survived replay and reopen but wrote private formats the landed Prometheus reader could not decode ([conformance decision](docs/TASK_SUITE_EVIDENCE.md#start-timestamp-conformance-decision)) | Remove the candidate-only writer/reader experiment and add an independent landed-format reader |
| Historical repeat run | On the then-current frozen bytes, 10/10 reference decisions returned `1` and 10/10 no-op decisions returned `0` without exceptions ([private evidence gates](docs/TASK_SUITE_EVIDENCE.md#private-evidence-gates)) | Keep repeatability as development evidence without relabeling older digests as final certification |
| Working alternatives | One registered independently written implementation per task passed, 5/5 ([candidate calibration](docs/TASK_SUITE_EVIDENCE.md#alternate-valid-and-mutant-calibration)) | Keep those cases as checks against accidental source-shape requirements |
| Wrong implementations | Fifteen named storage, flag, recovery, iterator, query, networking, and histogram defects failed, 15/15, on the historical corpus ([candidate calibration](docs/TASK_SUITE_EVIDENCE.md#alternate-valid-and-mutant-calibration)) | Keep the defects that failed for their intended behavior and replace any that did not discriminate |
| Historical bound gates | The 30-case full gate and 20-case repeat gate both reported balanced accuracy `1.0`, FAR `0.0`, and FRR `0.0` on their pinned task bytes ([private evidence gates](docs/TASK_SUITE_EVIDENCE.md#private-evidence-gates)) | Preserve them as dated development evidence |
| Upstream-conformance review | Agent trajectories exposed solutions that met broad behavior while missing reviewed Prometheus invariants ([verifier audit](docs/VERIFIER_PROVENANCE_AUDIT.md)) | Keep UDS pool identity, PromQL preprocessing, and landed start-timestamp format in the final task contracts; leave histogram and WAL checks behavioral |
| Final task check | All 5 references and 5 other working implementations passed; all 5 no-ops and 10 wrong implementations failed ([Daytona results](docs/TASK_SUITE_EVIDENCE.md#current-daytona-results)) | Freeze the five task packages and record the 25 decisions |
| Final evidence binding | Harbor metadata, candidate bytes, verifier receipts, and task checksums agreed for every final decision ([Daytona results](docs/TASK_SUITE_EVIDENCE.md#current-daytona-results)) | Report balanced accuracy `1.0`, FAR `0.0`, and FRR `0.0` for this fixed 25-case set |
| Prompt-matched Luna cohort | With no reasoning override, UDS, subquery, and WAL passed 2/2, start timestamp 1/2, and histogram 0/2; one subquery trial preceded the final exact-output control ([run table](docs/TASK_SUITE_EVIDENCE.md#prompt-matched-stock-agent-calibration)) | Keep the 7/10 result as development history, then rerun on final bytes |
| Final Luna cohort | Luna-high passed 2/10; both passes were stale WAL expiry. All trials completed without Harbor exceptions, cost `$2.59163820`, and took `3:15:24.21` in summed trial time ([final run table](docs/TASK_SUITE_EVIDENCE.md#final-byte-stock-agent-calibration)) | Keep it as the final difficulty snapshot and preserve representative trajectories |

The first and final Luna cohorts used different reasoning settings. Their 8/10 and 2/10 results mark the build's progression; they are not a controlled model comparison.

**Main failure mode:** start-timestamp persistence could reward storage that worked only when the candidate read its own format. The final task requires interoperability with the format Prometheus landed.

**Hot take:** Prometheus works better as one evolving RL environment than as five isolated PR exercises. Keep the episode runtime stable, then let the engineering problem move from networking to queries to storage.
